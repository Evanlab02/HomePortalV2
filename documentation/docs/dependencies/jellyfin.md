# Jellyfin

Home portal relies on some services and jellyfin is one of them. Jellyfin can be set up in alot of different ways and is really the primary use of home portal for me but since it can be set up in so many different ways and there are good reasons for doing it in different ways, I am not prescriptive of how you set it up. I prefer runnnig it baremetal and not containerized so I do not have to struggle with GPUs and containers working together but there is ways to work around this but this is up to you to decide.

## Setting Up Jellyfin

Refer to the documentation at the [Official Jellyfin Documentation](https://jellyfin.org/docs/general/installation/)
